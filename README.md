# 🌐 TrueIntern — Verified Internship Discovery Platform

**TrueIntern** is a modern, responsive web application designed to help students and early-career professionals discover, verify, and apply for audited internships across **250+ professional domains** with absolute transparency and zero friction.

---

## 🚀 Key Features

* **250+ Professional Domains:** Comprehensive coverage ranging from Computer Science, AI & Machine Learning, and Data Science to Content Creation, Corporate Law, Finance (B.Com/BBA), and Video Editing.
* **Trust Verification Badges:** 
  * 🛡️ **Verified:** Official corporate domains with guaranteed stipends and zero fees.
  * ⚠️ **Mild Verified:** Third-party hiring platforms requiring standard contract reviews.
  * ❌ **Not Trustable:** Flagged listings indicating upfront training deposit risks.
* **Dual-Channel Authentication & OTP:** Secure login simulation and Firebase-backed OTP verification (supporting Email and Mobile SMS).
* **Application Tracker:** Cloud-synced tracker using Firebase Firestore (with automatic local storage fallback) to manage application statuses (*Applied, Interviewing, Shortlisted, Rejected*).
* **Skill-Based Matcher:** Filter through a catalog of **130+ skills** to find exact matches for your portfolio.
* **AI Career Advisor:** Built-in smart chatbot drawer providing instant resume tips, remote role filtering, and scam-detection guidelines.

---

## 🛠️ Tech Stack

* **Frontend:** HTML5, Tailwind CSS (via CDN), Modern JavaScript (ES6+)
* **Backend & Database:** Firebase Auth & Firebase Firestore (v10)
* **Hosting:** GitHub Pages / Netlify / Vercel
